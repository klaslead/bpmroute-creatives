# bpmroute-creatives

Public social media creatives for BPMroute (images and reels used by Make, Buffer and Instagram).
This repo is public on purpose: Facebook and Instagram need a public URL to download each file.

## Folders

- `images/facebook/` – feed images for the Facebook page
- `images/instagram/` – Instagram images (JPEG only, 4:5 to 1.91:1, max 8 MB, width 320–1440 px)
- `reels/` – vertical videos (MP4, 9:16, 3–90 s, 1080x1920 recommended)

## Public link format

Use the raw link when mapping a file in Make:

```
https://raw.githubusercontent.com/klaslead/bpmroute-creatives/main/<path>
```

Example: `https://raw.githubusercontent.com/klaslead/bpmroute-creatives/main/images/instagram/launch-01.jpg`

Don't put anything private here. The main website code lives in the private `klaslead/bpmroute` repo.
